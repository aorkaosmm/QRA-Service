# QuestBar — Calendar RPG의 Windows 위젯

달력 위젯에 일정을 걸어 두고, 할 일·공부·업무·식사 같은 일일임무를 끝낼 때마다 **경험치와 전리품(골드 + 일반/희귀/영웅/전설 장비)** 을 얻어 도트 용사를 키우는 앱입니다.
용사는 **작업표시줄 위**에서 슬라임과 싸웁니다. 맞으면 뒤로 튕겨 나가고 머리 위로 데미지 숫자가 떠오르며, 임무를 끝내면 하늘에서 보물 상자가 떨어집니다.

> 지금 단계: Windows 위젯 (혼자 쓰는 로컬 앱). 온라인 소셜·모바일 연동은 아래 [로드맵](#로드맵) 참고.

## 받기 · 실행

### 1) 설치 파일 받기 (권장)

| 파일 | 설명 |
|---|---|
| [QuestBar-Setup-0.1.0.exe](https://github.com/aorkaosmm/QRA-Service/releases/download/calendar-rpg-v0.1.0/QuestBar-Setup-0.1.0.exe) | 설치판 (시작 메뉴·바탕화면 바로가기, 알림, Windows 시작 시 실행 지원) |
| [QuestBar-Portable-0.1.0.exe](https://github.com/aorkaosmm/QRA-Service/releases/download/calendar-rpg-v0.1.0/QuestBar-Portable-0.1.0.exe) | 설치 없이 바로 실행 |

- 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있어요 → **추가 정보 → 실행**
- `Calendar-RPG` 브랜치에 `questbar/`가 바뀌어 푸시되면 GitHub Actions가 Windows에서 다시 빌드해 위 링크의 파일을 새로 올립니다(같은 버전이면 주소 그대로).
- 다른 브랜치의 빌드 결과는 저장소 **Actions** 탭 → **QuestBar Windows build** → 실행 기록의 **Artifacts**(`QuestBar-Windows`)에서 받을 수 있어요.

### 2) 소스에서 바로 실행
[Node.js](https://nodejs.org/) 22 LTS 이상을 설치한 뒤:

```bash
cd questbar
```
```bash
npm install
```
```bash
npm start
```

### 3) 내 PC에서 설치 파일 만들기
```bash
npm run dist
```
`questbar/dist/` 에 `QuestBar-Setup-*.exe`, `QuestBar-Portable-*.exe` 가 생깁니다.

## 화면

| 탭 | 내용 |
|---|---|
| **캘린더** | 월간 달력(공휴일·대체공휴일 표시, 일정 칩, 일일임무 진행 막대, 퍼펙트 데이 왕관). 날짜를 누르면 그날 목록, 마우스 휠로 달 넘기기 |
| **오늘** | 오늘 진행도, 할 일 빠른 추가, 오늘 일정·할 일(밀린 할 일 포함), 분류별 일일임무(식사·공부·업무·할 일·운동·생활) |
| **가방** | 용사 능력치, 장착 슬롯(무기·투구·갑옷·망토), 장비 목록·비교·잠금·판매, 천장 카운터 |
| **상점** | 체력 물약, 보물 상자, 황금 보물 상자, **나만의 보상**(유튜브 30분 같은 보상을 직접 정해 골드로 사기), 최근 기록 |
| **설정** | 용사 이름, 일일임무 관리, 위젯·전투·알림 옵션, 데이터 내보내기/가져오기/초기화, 모험 기록 |

**작업표시줄 전투** (투명·클릭 통과 창)
- 용사가 슬라임을 찾아가 칼로 공격 → 데미지 숫자(치명타는 크게 노란색), 슬라임 넉백
- 슬라임에게 맞으면 **뒤로 튕겨 나가며** 빨간 데미지 숫자, 잠깐 무적(깜빡임). 체력이 0이면 기절했다가 부활
- 슬라임: 초록·파랑·빨강·보라(레벨에 따라 등장), 도망 다니는 메탈, 동전을 많이 주는 황금, 20마리마다 **킹 슬라임**
- 임무 완료 → `+EXP`·`+G`가 떠오르고 체력 회복, 장비가 나오면 **보물 상자가 떨어지고** 등급색 빛기둥(전설은 화면 번쩍)
- 용사를 누르면 위젯이 열리고, 슬라임을 누르면 직접 때릴 수 있어요. 가끔 말풍선으로 다가오는 일정이나 남은 임무를 알려 줍니다

## 보상 규칙

| 난이도 | 경험치 | 골드 | 장비 드롭 |
|---|---|---|---|
| 쉬움 ★ | 10 | 2~5 | 20% |
| 보통 ★★ | 20 | 5~10 | 30% |
| 어려움 ★★★ | 35 | 10~18 | 45% |

- 골드는 레벨이 오를수록 조금씩 늘고, 장비 드롭률은 **행운** 능력치만큼 오릅니다(최대 75%).
- **장비 등급 확률**: 일반 64% · 희귀 25% · 영웅 9% · 전설 2%
- **천장**: 장비 30번 안에 영웅 이상, 90번 안에 전설이 반드시 나옵니다(가방 탭에 남은 횟수 표시).
- **연속 달성**: 일일임무를 이어서 끝내면 하루마다 경험치 +3% (최대 +50%).
- **퍼펙트 데이**: 그날 일일임무를 모두 끝내면 보너스 상자(희귀 이상 확률 높음) + 30 EXP + 20G.
- **레벨업**: 처음 오른 레벨마다 보너스 골드, 5레벨마다 희귀 이상 장비.
- 슬라임 동전은 하루 최대 60G까지만 쌓입니다(임무가 주 수입원).
- 체크를 해제하면 받은 경험치·골드는 돌려놓고, 같은 날 다시 체크해도 장비를 다시 굴리지는 않습니다(체크 반복으로 장비 뽑기 방지).

장비 부위별 능력치: 무기 = 공격력 · 투구/갑옷 = 방어력·체력 · 망토 = 행운(치명타·드롭률)·공격력.
장착한 장비 등급에 따라 용사의 투구·갑옷·망토·칼 색이 바뀝니다(일반 철 → 희귀 파랑 → 영웅 보라 → 전설 금색).

## 조작

| 동작 | 방법 |
|---|---|
| 위젯 열기/숨기기 | 트레이 아이콘 클릭 · **Ctrl+Alt+Q** · 작업표시줄 용사 클릭 |
| 전투 표시/숨기기 | **Ctrl+Alt+B** · 트레이 메뉴 · 설정 탭 |
| 위젯 이동 / 크기 | 위쪽 용사 정보 영역을 끌기 / 오른쪽 아래 손잡이 끌기 |
| 탭 전환 | Ctrl+1 ~ Ctrl+5 |
| 종료 | 트레이 아이콘 우클릭 → 종료 (✕ 버튼은 숨기기) |

## 데이터

- 저장 위치: `%APPDATA%\QuestBar\questbar-save.json` (10분마다 `questbar-save.backup.json` 백업)
- 설정 탭 → **내보내기/가져오기**(JSON)로 다른 PC에 옮길 수 있고, 같은 형식을 향후 모바일 앱에서도 씁니다.

## 알려진 제한

- 전체 화면 동영상·게임 위에도 전투가 보일 수 있어요 → **Ctrl+Alt+B** 로 잠깐 숨기기
- 주 모니터의 작업표시줄 위에만 나옵니다. 작업표시줄이 옆/위에 있거나 자동 숨김이면 화면 맨 아래에 서요.
- 포터블판은 Windows 알림이 안 뜰 수 있어요(설치판 권장).
- "바탕화면 보기(Win+D)"에 고정되는 진짜 바탕화면 위젯 모드는 아직 없습니다(대신 '항상 위에 표시' 옵션).
- 음력 공휴일(설날·부처님오신날·추석)은 2025~2027년 표가 들어 있어요. 이후 연도는 `src/core/holidays.js`의 `LUNAR` 표에 추가합니다.

## 구조

```
questbar/
├─ src/core/        게임 엔진(순수 JS) — 보상·장비·레벨·일일임무·공휴일. 향후 모바일·서버에서도 그대로 사용
├─ src/shared/      도트 스프라이트 원본 데이터(직접 그림)와 래스터 변환
├─ src/main/        Electron 메인: 상태 보관·저장, 위젯/전투 창, 트레이, 알림, 단축키
├─ src/renderer/    위젯(widget/), 작업표시줄 전투(battle/), 공용 모듈(shared/)
├─ test/            엔진 단위 테스트 (npm test)
├─ assets/          글꼴(Galmuri, SIL OFL 1.1), 실행용 아이콘
└─ build/           설치 파일 아이콘
```

상태는 메인 프로세스 한 곳에서만 바뀝니다(렌더러는 `daily/toggle` 같은 액션만 보냄). 같은 엔진·액션 구조를 서버에 올리면 소셜 기능에서 보상을 서버가 검증할 수 있습니다.

### 개발용 명령

- `npm test` — 엔진 단위 테스트
- `npm run dev` — 개발자 도구를 띄운 채 실행
- `npm run icons` — 아이콘 다시 만들기
- 브라우저 미리보기: `questbar` 폴더에서 `python -m http.server 8765` 실행 후 `http://localhost:8765/src/renderer/preview.html` (위젯 + 작업표시줄 전투를 한 화면에서 확인)
- `electron . --smoke-test --smoke-out=폴더` — 두 창을 띄워 보상 처리·캡처 후 자동 종료(CI용, 실제 데이터는 건드리지 않음)

## 로드맵

1. **온라인 소셜** — 계정, 친구·파티, 파티원이 함께 잡는 보스(파티 퀘스트), 주간 랭킹. 서버가 `src/core` 엔진으로 보상을 검증
2. **모바일 앱 연동** — 같은 엔진을 쓰는 모바일 앱 + 서버 동기화(지금의 JSON 형식·ID 구조를 그대로 사용)
3. Windows 쪽 — 바탕화면 고정 모드, 다중 모니터, 전체 화면 앱 감지 자동 숨김
