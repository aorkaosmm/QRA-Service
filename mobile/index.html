홈 화면 위젯

위젯의 체크 버튼도 실제로 동작해요. 위젯에서 체크하면 앱 화면의 용사가 같은 보상을 받습니다.

모바일에서 용사와 슬라임은?

Android는 PC처럼 앱 밖에서도 용사를 계속 띄울 수 있어요. iPhone은 실시간 전투가 앱 안에서만 되고, 위젯에서는 용사 상태를 그림으로 보여 주는 정도예요.

Android

  • 홈 화면 라이브 배경화면 — 배경화면으로 지정하면 홈 화면 아래쪽에서 용사가 슬라임과 싸워요. 특별한 권한이 필요 없고, 홈 화면이 보일 때만 움직여서 배터리 부담이 작아요. 추천
  • 다른 앱 위에 표시 — PC 작업표시줄처럼 모든 앱 위에 용사를 띄울 수 있어요. 대신 사용자가 권한을 직접 켜야 하고, 실행 중 알림이 계속 떠 있고, 터치가 아래 앱으로 통과하도록 용사가 살짝 반투명해져요.
  • 홈 화면 위젯 — 달력·오늘의 임무 체크·용사 상태. 위젯 안 용사는 2~4장짜리 간단한 움직임까지 가능해요.
  • 앱 안 전투 — 화면 아래 띠에서 PC와 똑같이 싸워요.

iPhone

  • 앱 안 전투 — 실시간 전투는 앱을 열었을 때만 보여요.
  • 홈·잠금 화면 위젯 — 달력과 오늘의 임무를 보여 주고, iOS 17부터는 위젯에서 바로 체크할 수 있어요. 용사는 정지 화면이고, 체크하면 슬라임이 맞는 짧은 전환 연출 정도가 가능해요. 위젯 새로 고침 횟수는 하루 수십 번으로 제한돼요.
  • 실시간 현황(Live Activity) — 진행 중인 일정·집중 타이머를 잠금 화면과 다이내믹 아일랜드에 띄워요.
  • 안 되는 것 — 다른 앱 위에 계속 띄우기, 직접 만든 움직이는 배경화면은 iOS가 허용하지 않아요.

PC와 연동은 이렇게

  1. 같은 계정으로 로그인하면 일정·일일임무·레벨·장비가 서버로 동기화돼요.
  2. 폰 위젯에서 「점심 식사」를 체크하면, 몇 초 안에 PC 작업표시줄의 용사에게 경험치와 보상 상자가 떨어져요.
  3. 보상 계산은 서버가 같은 게임 규칙 엔진으로 한 번 더 확인해서, 친구 랭킹·파티 퀘스트에서 공정하게 비교돼요.

만드는 방법

  • 게임 규칙(보상·장비·일일임무·공휴일)은 지금 Windows 앱의 엔진을 그대로 씁니다. 이 시안도 같은 코드로 돌아가요.
  • 앱 화면은 지금 위젯 화면을 모바일 크기로 다듬어 재사용하고, 위젯은 각 운영체제 기본 기술로 따로 만듭니다(Android Glance · iOS WidgetKit).
  • Android 라이브 배경화면은 같은 도트 그림 데이터를 옮겨 그립니다.
  • 동기화·소셜 기능을 위해 계정 서버가 필요해요(다음 단계).
