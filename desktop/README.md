# Calendar RPG — Windows 위젯

달력 위젯에 일정을 걸어 두고, 할 일·공부·업무·식사 같은 일일임무를 끝낼 때마다 **경험치와 전리품(골드 + 일반/희귀/영웅/전설 장비)** 을 얻어 도트 용사를 키우는 앱입니다.
용사는 **작업표시줄 위**에서 슬라임과 싸웁니다. 맞으면 뒤로 튕겨 나가고 머리 위로 데미지 숫자가 떠오르며, 임무를 끝내면 하늘에서 보물 상자가 떨어집니다.

> 지금 단계: Windows 위젯 (혼자 쓰는 로컬 앱). 온라인 소셜·모바일 연동은 아래 [로드맵](#로드맵) 참고.

## 받기 · 실행

### 1) 설치 파일 받기 (권장)

| 파일 | 설명 |
|---|---|
| [CalendarRPG-Setup-0.3.0.exe](https://github.com/aorkaosmm/QRA-Service/releases/download/calendar-rpg-v0.3.0/CalendarRPG-Setup-0.3.0.exe) | 설치판 (시작 메뉴·바탕화면 바로가기, 알림, Windows 시작 시 실행 지원) |
| [CalendarRPG-Portable-0.3.0.exe](https://github.com/aorkaosmm/QRA-Service/releases/download/calendar-rpg-v0.3.0/CalendarRPG-Portable-0.3.0.exe) | 설치 없이 바로 실행 |

- 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있어요 → **추가 정보 → 실행**
- `Calendar-RPG` 브랜치에 `desktop/`이 바뀌어 푸시되면 GitHub Actions가 Windows에서 다시 빌드해 위 링크의 파일을 새로 올립니다(같은 버전이면 주소 그대로).
- 다른 브랜치의 빌드 결과는 저장소 **Actions** 탭 → **Calendar RPG Windows build** → 실행 기록의 **Artifacts**(`CalendarRPG-Windows`)에서 받을 수 있어요.

### 2) 소스에서 바로 실행
[Node.js](https://nodejs.org/) 22 LTS 이상을 설치한 뒤:

```bash
cd desktop
```
```bash
npm install
```
```bash
npm start
```

### 3) 내 PC에서 설치 파일 만들기
```bash
npm run dist
```
`desktop/dist/` 에 `CalendarRPG-Setup-*.exe`, `CalendarRPG-Portable-*.exe` 가 생깁니다.

## 화면

| 탭 | 내용 |
|---|---|
| **캘린더** | 월간 달력(공휴일·대체공휴일, 일정 그룹 색 막대 — **여러 날 일정은 칸을 가로질러 이어진 막대**, 일일임무 진행 막대, 퍼펙트 데이 왕관). 날짜·막대를 누르면 그날 목록, 마우스 휠로 달 넘기기 |
| **오늘** | 오늘 진행도, 할 일 빠른 추가, 오늘 일정·할 일(밀린 할 일 포함), 분류별 일일임무(식사·공부·업무·할 일·운동·생활) |
| **가방** | 용사 능력치, 장착 슬롯(무기·투구·갑옷·망토), 장비 목록·비교·잠금·판매, 천장 카운터 |
| **상점** | 체력 물약, 보물 상자, 황금 보물 상자, **나만의 보상**(유튜브 30분 같은 보상을 직접 정해 골드로 사기), 최근 기록 |
| **설정** | 용사 이름, 일일임무 관리, **일정 그룹 관리**, 위젯·전투·알림 옵션, 데이터 내보내기/가져오기/초기화, 모험 기록 |

**일정 추가** — 제목 오른쪽의 **일정 그룹** 상자(기본·개인·회사·가족, 새 그룹 바로 만들기)에서 그룹을 고르면 달력 막대가 그 그룹 색으로 칠해집니다(기본 그룹은 임무 분류 색). **시작 날짜·종료 날짜**를 넣을 수 있고, 시작 날짜를 고르면 종료 날짜가 같은 날로 맞춰집니다. 여러 날 일정은 기간 중 아무 날에나 한 번 체크하면 완료돼요.

**작업표시줄 전투** (투명·클릭 통과 창)
- 용사 머리 위에 **체력바가 항상** 보이고, 위젯 머리말에도 같은 체력이 표시됩니다
- 용사가 슬라임을 찾아가 칼로 공격 → 데미지 숫자(치명타는 크게 노란색), 슬라임 넉백
- 슬라임에게 맞으면 **뒤로 튕겨 나가며** 빨간 데미지 숫자, 잠깐 무적(깜빡임). 체력이 0이면 기절했다가 부활
- 슬라임: 초록·파랑·빨강·보라(레벨에 따라 등장), 도망 다니는 메탈, 동전을 많이 주는 황금, 20마리마다 **킹 슬라임**
- 임무 완료 → `+EXP`·`+G`가 떠오르고 체력 회복, 장비가 나오면 **보물 상자가 떨어지고** 등급색 빛기둥(전설은 화면 번쩍)
- 용사를 누르면 위젯이 열리고, 슬라임을 누르면 직접 때릴 수 있어요. 가끔 말풍선으로 다가오는 일정이나 남은 임무를 알려 줍니다

## 보상 규칙

| 난이도 | 경험치 | 골드 | 장비 드롭 |
|---|---|---|---|
| 쉬움 ★ | 10 | 2~5 | 20% |
| 보통 ★★ | 20 | 5~10 | 30% |
| 어려움 ★★★ | 35 | 10~18 | 45% |

- 골드는 레벨이 오를수록 조금씩 늘고, 장비 드롭률은 **행운** 능력치만큼 오릅니다(최대 75%).
- **장비 등급 확률**: 일반 64% · 희귀 25% · 영웅 9% · 전설 2%
- **천장**: 장비 30번 안에 영웅 이상, 90번 안에 전설이 반드시 나옵니다(가방 탭에 남은 횟수 표시).
- **연속 달성**: 일일임무를 이어서 끝내면 하루마다 경험치 +3% (최대 +50%).
- **퍼펙트 데이**: 그날 일일임무를 모두 끝내면 보너스 상자(희귀 이상 확률 높음) + 30 EXP + 20G.
- **레벨업**: 처음 오른 레벨마다 보너스 골드, 5레벨마다 희귀 이상 장비.
- 슬라임 동전은 하루 최대 60G까지만 쌓입니다(임무가 주 수입원).
- 체크를 해제하면 받은 경험치·골드는 돌려놓고, 같은 날 다시 체크해도 장비를 다시 굴리지는 않습니다(체크 반복으로 장비 뽑기 방지).

장비 부위별 능력치: 무기 = 공격력 · 투구/갑옷 = 방어력·체력 · 망토 = 행운(치명타·드롭률)·공격력.
장착한 장비 등급에 따라 용사의 투구·갑옷·망토·칼 색이 바뀝니다(일반 철 → 희귀 파랑 → 영웅 보라 → 전설 금색).

## 던전 · 랭킹 · 채팅

| 콘텐츠 | 규칙 |
|---|---|
| **필드 보스** | 매일 **오후 9시**에 '거대 황금 슬라임 왕'이 나타나 **5분** 동안 싸웁니다. 한 맵 **20명**, 파티는 **4명까지** 함께 입장. 들어가면 끝날 때까지 자동으로 싸우고(앱을 닫아도), 화면을 누르거나(초당 5번까지) 필살기(15초마다)를 쓰면 피해가 커집니다. **딜 누적 순위**대로 보상: 1위 골드 600·보석 30·영웅 이상 장비 / 2~3위 400·20·희귀 이상 장비 / 4~10위 250·12·장비 60% / 11~20위 120·6 (골드는 전투력 단계마다 +15%). 언제든 **연습하기**로 미리 해 볼 수 있어요(보상 없음) |
| **요일 던전** | 요일마다 다른 던전에 **하루 1시간** 들어갈 수 있고, 들어가 있는 동안 용사가 자동으로 사냥해 보석을 모읍니다(1분에 1개, 전투력 단계마다 +10%). 월 루비(불꽃 동굴) · 화 호박석(호박빛 사막) · 수 토파즈(번개 탑) · 목 에메랄드(이끼 숲) · 금 사파이어(심해 신전) · 토 자수정(그림자 성) · **일요일은 6색 모두**(무지개 보물고) |
| **레이드** | 입장권이 **매일 1개씩**(최대 10개, 처음 3개) 채워집니다. 전투력 **10단계**마다 레이드 보스가 있고 내 단계까지 도전 가능. 60초 안에 쓰러뜨리면 **레이드 보물상자**(레이드 전용 장비 — 같은 레벨보다 능력치 35%↑ — + 골드·보석·경험치, 확률로 장비 1개 더·황금 상자 장비). **성공할 때만** 입장권을 씁니다 |
| **전투력** | 공격·방어·체력·행운·레벨로 계산한 한 숫자. 10단계(0 · 300 · 600 · 1000 · 1500 · 2100 · 2800 · 3600 · 4500 · 5500~) |
| **전투력 랭킹** | 1~3위는 금·은·동 시상대 위에 캐릭터가 서고, 아래는 순위 목록, 맨 아래 줄은 항상 내 순위 |
| **채팅** | 필드(지금 필드의 무작위 대화) · 파티 · 길드 · 시스템(내 전설 획득·레벨 업·레이드 토벌·필드 보스 결과·오후 9시 예고) |

## 데이터

- 저장 위치: `%APPDATA%\Calendar RPG\calendar-rpg-save.json` (10분마다 `calendar-rpg-save.backup.json` 백업)
- 이전 이름(QuestBar)으로 쓰던 데이터는 처음 실행할 때 자동으로 옮겨집니다. 옮긴 뒤에는 예전 QuestBar를 제거해 주세요.
- 설정 탭 → **내보내기/가져오기**(JSON)로 다른 PC에 옮길 수 있고, 같은 형식을 향후 모바일 앱에서도 씁니다.

## 알려진 제한

- 전체 화면 동영상·게임 위에도 전투가 보일 수 있어요 → **Ctrl+Alt+B** 로 잠깐 숨기기
- 주 모니터의 작업표시줄 위에만 나옵니다. 작업표시줄이 옆/위에 있거나 자동 숨김이면 화면 맨 아래에 서요.
- 포터블판은 Windows 알림이 안 뜰 수 있어요(설치판 권장).
- "바탕화면 보기(Win+D)"에 고정되는 진짜 바탕화면 위젯 모드는 아직 없습니다(대신 '항상 위에 표시' 옵션).
- 음력 공휴일(설날·부처님오신날·추석)은 2025~2027년 표가 들어 있어요. 이후 연도는 `src/core/holidays.js`의 `LUNAR` 표에 추가합니다.

## 구조

```
desktop/
├─ src/core/        게임 엔진(순수 JS) — 보상·장비·레벨·일일임무·공휴일, 던전·레이드 규칙(adventure.js), 가상 플레이어(world.js). 모바일·서버에서도 그대로 사용
├─ src/shared/      도트 스프라이트 원본 데이터(직접 그림)와 래스터 변환
├─ src/main/        Electron 메인: 상태 보관·저장, 위젯/전투 창, 트레이, 알림, 단축키
├─ src/renderer/    위젯(widget/), 작업표시줄 전투(battle/), 공용 모듈(shared/)
├─ test/            엔진 단위 테스트 (npm test)
├─ assets/          글꼴(Galmuri, SIL OFL 1.1), 실행용 아이콘
└─ build/           설치 파일 아이콘
```

상태는 메인 프로세스 한 곳에서만 바뀝니다(렌더러는 `daily/toggle` 같은 액션만 보냄). 같은 엔진·액션 구조를 서버에 올리면 소셜 기능에서 보상을 서버가 검증할 수 있습니다.

### 개발용 명령

- `npm test` — 엔진 단위 테스트
- `npm run dev` — 개발자 도구를 띄운 채 실행
- `npm run icons` — 아이콘 다시 만들기
- 브라우저 미리보기: `desktop` 폴더에서 `python -m http.server 8765` 실행 후 `http://localhost:8765/src/renderer/preview.html` (위젯 + 작업표시줄 전투를 한 화면에서 확인)
- `electron . --smoke-test --smoke-out=폴더` — 두 창을 띄워 보상 처리·캡처 후 자동 종료(CI용, 실제 데이터는 건드리지 않음)

## 로드맵

1. **온라인 소셜** — 던전·파티·길드·랭킹·채팅 화면과 규칙은 들어갔고(지금은 가상 플레이어), 계정 서버가 생기면 실제 플레이어로 바꿉니다. 서버가 `src/core` 엔진으로 보상을 검증하고, 길드는 길드 업무 일정 취합·통계까지
2. **모바일 앱 연동** — 같은 엔진을 쓰는 모바일 앱 + 서버 동기화(지금의 JSON 형식·ID 구조를 그대로 사용)
3. Windows 쪽 — 바탕화면 고정 모드, 다중 모니터, 전체 화면 앱 감지 자동 숨김
